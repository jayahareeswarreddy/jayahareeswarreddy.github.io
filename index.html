PROMPT · UI BUILDER

Prompt-to-UI Generator

A deterministic prompt-driven React UI builder: the same prompt produces the same interface.

  • Livepreviews
  • Repeatableoutput
  • Versionrollback
  • React 19
  • TypeScript
  • Vite
  • Tailwind CSS
  • Node.js
  • Express
Open case study

Problem

Free-form generation can return broken markup, drift away from a design system, and make it hard to explain how a screen was produced. A model call also adds latency, cost, and credentials to a demo.

Approach

  • Plan: convert the prompt into a typed UI plan for layout, tone, approved components, and content; carry the previous plan forward for incremental edits.
  • Validate: reject missing fields and unapproved components before rendering.
  • Generate and explain: compose JSX from the whitelisted library, explain structural choices, and save versions for comparison and rollback.

Architecture

  • Prompt
  • Typed planner
  • Validator
  • Whitelisted JSX
  • Preview + history

The generation pipeline runs client-side as pure TypeScript functions; no model call or API key is needed.

Outcome & trade-off

The same prompt and plan produce repeatable screens, invalid component requests fail before rendering, and users can inspect or roll back versions. The fixed component library intentionally limits the range of interfaces the tool can create.

RAG · EVALUATION

RAG Eval

Measures retrieval quality against labelled questions instead of relying on intuition.

  • 27configurations evaluated
  • 875Python modules
  • Python
  • FastAPI
  • NumPy
  • RAG Evaluation
Open case study

Problem

A RAG answer can sound plausible even when retrieval missed the useful passage. Without labelled questions and ranking metrics, changing chunking or retrieval is guesswork—and generation can hide retrieval failures.

Approach

  • Built a benchmark from 875 Python standard-library modules and 930 docstring-derived questions; evaluated 27 configurations on a 150-question development split.
  • Compared fixed, recursive, Markdown-aware, and Python AST chunking with BM25, dense, and reciprocal-rank-fusion hybrid retrieval.
  • Measured Recall@k, MRR, nDCG, and latency percentiles. Each generated sentence carries a citation checked against its source passage; without an LLM key, answers are extractive.

Architecture

  • Documents
  • Chunk strategies
  • BM25 / dense / hybrid
  • Ranked passages
  • Cited answer + metrics

FastAPI serves search, upload, grounded Q&A, and evaluation. Uploaded text is memory-resident, size-limited, and expires.

Findings

On this corpus, AST chunks with BM25 reached 0.960 top-1; hybrid retrieval did not improve that result. The benchmark questions come from docstrings and share vocabulary with the source, so this describes this dataset—not every user's documents. Larger chunks also reduced dense retrieval quality.

Engineering lesson

An overnight-suspension outlier distorted an early latency mean. The harness now reports p50, p95, and maximum latency instead, making the measurement limit visible rather than hiding it in an average.

LLM · CAREER

FutureTrackAI

Career guidance that maps skills to relevant roles and practical learning roadmaps.

  • 14FastAPI endpoints
  • 24career paths
  • Python
  • FastAPI
  • Groq / OpenAI
  • MongoDB
  • React
Open case study

Problem

Career suggestions are more useful when people can see how their current skills fit a role and what they could learn next. Model-only recommendations can be inconsistent, difficult to validate, or unavailable when a provider key is missing.

Approach

  • Rank skills against a curated catalogue of 24 career paths with deterministic weighted matching; keep role scores and skill-gap arithmetic outside the model.
  • Use Groq by default or configure OpenAI for explanations and roadmap detail. Validate generated JSON against schemas, retry with validation feedback, then fall back to rule-based responses.
  • Keep MongoDB optional: saved profiles persist when it is available, while the service remains usable with an in-memory store without it.

Architecture

  • React skills form
  • FastAPI
  • Deterministic role scoring
  • Optional LLM enrichment
  • Validated results

Provider calls run off the async event loop; health reporting exposes retries, schema rejections, and fallback counts.

Outcome

The service returns structured role matches, skill gaps, and learning roadmaps through 14 endpoints. 43 API tests run without MongoDB or an API key, exercising the fallback path as a supported configuration.
